partner name as text instead, so nothing breaks.

## File requirements

- **Format** PNG with a transparent background (SVG also works — change the
  extension in the `img.src` line of the page if you switch).
- **Colour** solid near-black (`#0D0D0D`). The page inverts them to white on hover,
  so a single-colour mark works best.
- **Size** roughly 600–1000 px on the long edge. They are displayed at a capped
  height of 56 px, so anything above ~600 px is plenty for retina.
- **Padding** trim all transparent margin from the file. The page adds its own
  padding; built-in whitespace is what makes logos look misaligned.
- **Optical sizing** the cap is on height, so a very wide wordmark and a compact
  square mark will already read at similar visual weight. If one still looks too
  large or small, add a little transparent padding to that single file to nudge it.

Most of these are published as official press/brand assets:

- KFDA — kfda.or.kr
- Seoul Metropolitan Government — seoul.go.kr (brand identity / CI page)
- Seoul Design Foundation — seouldesign.or.kr
- Genesis — genesis.com press/media kit
- LG Labs (DUOBO) — lglabs.com
- UNDP — undp.org brand manual (logo use requires their permission)
- Hongik University / Hongik IDAS — hongik.ac.kr, idas.hongik.ac.kr

Check each organisation's brand guidelines before publishing — several (UNDP in
particular) require written approval for logo use.
